# Convolution neural network (CNN)

## Overview

- This section studies Convolution neural network (CNN) from its mathematical operation to build a CNN for image classification using Pytorch

## Goal

- Understanding why this neural network is suitable for image data
- How kernel transforms data by conv operation + how stride, padding, maxpooling have effect on the output and formulae for the output + formulae for output shape
- Understanding the process of applying convolution to multi-channel image
- Building a CNN for image classification and compare its performance to old MLP classifier, in the same dataset (using Pytorch)
